# GKD Deduplicated

由公开的 GKD 合并订阅整理而成，合并同一应用中执行行为相同的重复规则组。

## 订阅链接

```text
https://raw.githubusercontent.com/Skyrainer/gkd-deduplicated/main/dist/gkd.json5
```

## 处理结果

- 软件：318 个（按精选清单保留）
- 规则组：1,667 个
- 规则：3,166 条
- 已合并重复规则组：454 个（本次，应用内同名且行为等价）

名称相同但触发条件、动作链或时序不同的规则不会被合并。
