# GKD Deduplicated

由公开的 GKD 合并订阅整理而成，合并同一应用中执行行为相同的重复规则组。

## 订阅链接

```text
https://raw.githubusercontent.com/Skyrainer/gkd-deduplicated/main/dist/gkd.json5
```

## 处理结果

- 软件：318 个（按精选清单保留）
- 规则组：1,530 个
- 规则：2,954 条

### 去重轮次

- 第一轮：合并应用内同名且行为等价的重复规则组 454 个
- 第二轮（version 3）：对 22 个高频应用（微信、淘宝、支付宝、哔哩哔哩、知乎、京东等）做深度去重——组内重复键、跨组等价/包含、快照证据同源的近似分组，净减规则组 126 个、重复规则 143 条
- 第三轮（version 4）：知乎同语义分组重构——信息流/推荐页/回答底部/评论区广告卡片七组合并为统一两段式链路（点 × → 不感兴趣 → 原因/确认），修复原 preKeys 断链与第二段页面缺口；弹窗广告 vid/id 双写、通知引导、自动展开回答等组内去重，17 组并至 10 组、规则 65 条并至 50 条
- 第四轮（version 5）：微信同语义分组重构——朋友圈广告简/繁/英三组并一；订阅号文章页与消息页两段式两组合一并修复 preKeys 断链；未读消息点击两组合一；登录授权（20→11）、小程序广告（15→8）、红包结算返回（4→2）等组内跨源重复清理，37 组并至 33 组、规则 130 条并至 93 条
- 第五轮（version 6）：全库 53 软件批量去重——同键规则重编号 145 处（下游 preKeys 引用同步，保持触发语义不变）、精确重复合并 14 条、空 preKeys 字段清理 34 处、删除源头遗留死规则 3 条（悬空 preKeys 自上游合并起即无效），全库同键/精确重复/悬空引用清零，规则 2,971→2,954 条

名称相同但触发条件、动作链或时序不同的规则不会被合并。
